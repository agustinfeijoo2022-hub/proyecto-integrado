# FYAG · Sistema de gestión logística

La aplicación actual está en [Sistema de Gestión FYAG](Sistema%20de%20Gesti%C3%B3n%20FYAG/README.md). Incluye inventario, obras y materiales, compras, clientes y presupuestos, facturación y cobranza, auditoría y un panel gerencial.

Para ejecutar el proyecto en local, abre esa carpeta en Visual Studio Code. Instala las dependencias con `npm ci`, crea tu configuración local a partir de `.env.example` y sigue la guía del proyecto para levantar el servidor y el frontend.

El Centro de ayuda reúne el recorrido por pantalla, preguntas frecuentes y el flujo de trabajo de cada perfil. La portada lleva al acceso con cuenta de trabajo.
